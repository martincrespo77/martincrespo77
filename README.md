## 👋 Sobre mí

Soy **Martín**, estudiante de **5.º año de Ingeniería en Informática** en la **Facultad de Ingeniería del Ejército (FIE – UNDEF)**.

Me gusta construir software que resuelva problemas concretos: desde **APIs REST con arquitectura en capas** hasta **firmware para microcontroladores** que mueve motores y lee sensores. Disfruto ese punto donde el código toca el hardware.

- 🔭 Ahora mismo: **Mesa de Ayuda** para una cooperativa de servicios (FastAPI + web + escritorio, en Docker).
- ⚡ En paralelo: **seguidor solar de 2 ejes con ESP32** y **comunicación láser entre dos ESP32**.
- 🌱 Aprendiendo: Spring Boot, testing automatizado, Docker y herramientas de IA para desarrollo (MCP).
- 🤝 Busco: mi **primera experiencia profesional / pasantía** en desarrollo backend o sistemas embebidos.
- 📍 Buenos Aires, Argentina
